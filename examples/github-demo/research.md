# Topic research notes

Add source URLs, access date, fact-check notes and pronunciation/name guidance here
for each new reel. Prefer primary/official sources for current claims.

# Asset sourcing notes

Every downloaded visual file must have a matching entry in `assets.json`. Log the
source, exact license or brand-use terms, intended use, required credit, and
whether the asset is official, openly licensed, or a screenshot. Never assume a
public URL grants reuse rights. If unclear, make a code-built visual instead.
